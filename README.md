# miniguia-estudos-notebooklm
Miniguia de estudos sobre finanças pessoais para iniciantes, criado com o NotebookLM a partir de fontes oficiais (Banco Central, CVM e Tesouro Direto). Inclui curadoria de fontes, engenharia de prompts, troubleshooting, resumos, glossário e prompts reutilizáveis. Desafio DIO.
